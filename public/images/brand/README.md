# Brand Assets

This directory contains brand-specific imagery for the Scanminers website.

## Starfield Background

Add `stars-soft.webp` here - a subtle, repeating star pattern texture for the night-sky background effect.

Recommended specs:

- Size: 600x600px
- Format: WebP (for performance)
- Style: Very subtle stars on transparent/dark background
- Opacity will be set to 0.12 in CSS, so the texture should be fairly visible

The starfield will tile across the page background, creating a calm night-sky atmosphere without interfering with content readability.
