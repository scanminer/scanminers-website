# AI Content Briefs

This directory stores content briefs created through the Decap CMS admin interface.

Each brief contains:
- **Topic/Title**: The main subject for the AI-generated content
- **Context**: Detailed notes, key points, data, or references for the AI
- **Status**: Tracks the workflow (New Brief → Generating Draft → Draft Ready)

These briefs are picked up by the automated content generation workflow.
